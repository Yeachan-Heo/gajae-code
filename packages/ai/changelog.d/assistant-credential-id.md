### Added

- `AssistantMessage.credentialId` records the stored credential row that authenticated the request producing the message. `streamSimple` stamps `StreamOptions.credentialId` on every partial, the `done` or `error` message, and the stream result; an auth retry that returns an `AuthRetryCredential` with its own `credentialId` attributes the retried response to that row, while a bare replacement key leaves the field unset. The value is the opaque, non-secret row id only, and it is never set for external, env, or pi-native gateway keys. Attribution is best-effort and never fails a request whose message object rejects the write. An attributed request now aborts its provider request when the consumer stops iterating early, matching the auth-retry path. `pi-native-client` no longer forwards `credentialId` to the gateway.
