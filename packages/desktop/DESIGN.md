# Gajae Code Desktop

## Workflow: EXISTING DESIGN SYSTEM

Extend the existing warm-neutral desktop system, component library and `?showcase` harness. This is not a greenfield redesign. Preserve project organization, parallel conversations, long-running work and reviewable outputs in a first-party GJC interface. Codex-style means compact navigation and a quiet reading/composing workspace, not copied branding, vendor assets or product claims. Historical reference: https://developers.openai.com/codex/app/ (retrieved 2026-10-27; redirected to https://learn.chatgpt.com/docs/app); no third-party material is vendored.

## Layout

Muted 264px left sidebar groups conversations by project, displaying running/waiting/error independently of selection. Compact toolbar names the selected project/session. Central conversation reading column and sticky bottom composer. Optional right changed-files/diff pane. Settings and command navigation require no terminal. Empty states offer a single primary action.

## Tokens

System sans-serif, 14px (0.875rem) base, line-height 1.55; medium-weight compact headings and 12px secondary metadata. Use rem typography so browser text scaling remains effective. Monospace is reserved for paths, code and tool output. Assistant prose and display reasoning use semantic safe Markdown; user text and tool output keep their original whitespace. Warm backgrounds #faf9f6 main, #f0efeb sidebar, #ffffff cards; text #242424, muted #64645f, border #deddd7, accent #23694f, error #a42f35. Dark colors #191a19/#222421/#2b2e29, text #eceee7, muted #b3b7ab, border #42473d. Separate subtle decorative borders from stronger input boundaries; primary-button text uses its own contrast token. Accent/error tinted surfaces are quiet and never the sole status indicator. Spacing 4/8/12/16/24/32px. Radius 8px controls, 14px composer/cards. Lucide icons are 16px, decorative next to text, and never replace accessible names. Text contrast >=4.5:1. No decorative gradients, oversized hero copy or per-card shadows.

## Ownership

The app's catalog, transcripts and logs live under its desktop data root. Agent configuration, credentials, model profiles and the default preset share the terminal installation by default; `GJC_DESKTOP_ISOLATED=1` gives tests/QA an isolated install. Initial target macOS 15+ arm64 (WebView must support Promise.withResolvers). Closing last window hides app while tasks continue; explicit Quit cancels/disposes owned work. #7322 owns upstream parity; consume public SDK, never private endpoints or terminal controllers. Expose unavailable capabilities truthfully pending upstream implementation.

## Compact reading and native interaction

Assistant responses and reasoning use React-rendered Markdown tokens, never raw HTML injection. Escape raw HTML, reject unsafe link schemes and render Markdown image alt text without remote fetches; inline protocol images retain their separate privacy and size checks. Fenced code has bounded horizontal scrolling and an explicit copy action with success/failure feedback; copy matches the rendered logical code, excluding container prefixes, fences and UI labels, with Markdown-normalized LF line endings. User messages and tool output remain literal.

Only owned panes scroll: conversation, sidebar, bounded queue, composer overflow and modal content, with a workspace overflow fallback for constrained heights or recovery notices. The document never scrolls. Composer font metrics are independently observed so existing multiline drafts resize when text scaling changes. Modal headers stay fixed above `.modal-content`; close buttons are accessible X icons. Suppress the browser context menu inside the app without blocking normal typing, paste or keyboard selection. Controls share compact boundaries, heights and radii; routine running status says only `작업 중`. Keep actionable recovery and error feedback, not repeated helper prose.

Session names come from the SDK's first-accepted-input automatic-title operation. `New session` is a catalog display placeholder, never a user-sourced transcript title. Manual renames win, retired owners cannot apply late generation, and a committed SDK title remains authoritative if its redundant catalog cache write fails; reopening reconciles that cache. Title work never changes delivery disposition.

## Native boundary

Rust is limited to `packages/desktop/src-tauri`: Tauri window integration, sidecar process lifecycle, and validated IPC transport. SDK behavior and application business logic remain in TypeScript. The repository Rust scope guard checks the `gjc-desktop` package identity and rejects Rust outside this native directory, including sibling desktop application code.

## Account authorization

The app uses public AuthStorage login callbacks with a single app-owned authorization flow. Provider selection, an explicit HTTPS-only system-browser action, optional code prompts, cancellation and reopening settings are supported. Prompt answers are never persisted in frontend storage. Cancellation does not undo credentials a provider already saved; an uncooperative provider may require Quit and relaunch before another login. This is not proof of a completed real-provider login.

Before the SDK captures environment state, the sidecar strips inherited provider keys/tokens, routing/proxy overrides and CLI broker state. Shared mode restores the installation's HOME and resolved agent directory (including explicit agent-directory overrides); credentials remain in the SDK's shared storage, not a new Keychain implementation. `GJC_DESKTOP_ISOLATED=1` instead places HOME, agent, configuration and XDG roots under the app data directory for tests/QA. Neither mode is an execution sandbox for SDK tools.

## Delivery recovery and process ownership

Before clearing the composer, atomically retain its original text and ready attachment payloads in local IndexedDB. The host retains metadata-only delivery receipts and acknowledgment tombstones. Durable handoff and SDK preflight acceptance are not proof that a model run executed. Definitive refusal is distinct from provider failure, cancellation, and an unknown outcome; a disconnect or restart must never automatically replay potentially executed input.

Normal pending, accepted and queued delivery receipts remain durable internal bookkeeping, not recovery warnings; reconcile bootstrap receipts before exposing an unmatched record as unknown. Successful completion/cancellation and automatic definitive-refusal restoration do not flash alarming cards. Actionable unknown outcomes explain possible prior execution; failed outcomes use distinct copy without promising that execution never started. Known-unsent storage repair remains separate from acknowledgment failure. Unknown/failed recovery requires an explicit user action; definitive refusal/removal restores safely without replay. Restore preserves newer draft text and attachments; acknowledging the recovery record does not erase the restored draft. Network acknowledgment is bounded and does not hold the local draft-write queue. Repair and disposal controls belong to an exact delivery ID, not every delivery in the same session; unresolved known-unsent repair cannot be discarded.

The process entrypoint registers host teardown and final frame draining with the shared signal-exit owner. It does not race an independent LSP exit handler or remove unrelated signal listeners. Protocol-requested shutdown is a normal zero exit; SIGTERM retains the shared conventional status. Signal cleanup remains bounded by the existing postmortem deadline (5 seconds by default, configurable with `GJC_CLEANUP_DEADLINE_MS`); expiry can interrupt teardown or final frame flushing, so it is not a guaranteed-delivery contract. Unproven deliveries remain recoverable as unknown. QA fixtures use the same process lifecycle and observe real MCP transport termination and LSP process exit rather than inferring teardown from a stale-session error.

It is App/Host/SDK transport proof, not a live provider or native-WebView check.

Run `bun test packages/desktop/test packages/desktop-host/test` for durable recovery, exact wire-envelope limits, mounted composer failures, causal error ownership, trusted extension input/startup, real owned MCP/LSP effects and teardown, and actual wrapper HTTP/SSE shutdown. Run `cargo test --manifest-path packages/desktop/src-tauri/Cargo.toml` separately for native frame validation and sidecar lifecycle. These fixtures use isolated credentials and owned loopback services, not live provider accounts. Intentional QA shutdown drains diagnostics and final event frames boundedly; failure diagnostics redact fixture tokens.
