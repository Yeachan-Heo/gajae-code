### Added

- The conversation toolbar has a `Session status` button that opens a compact status panel with the same fields as the TUI status line: model, reasoning level, context use, cost, branch, pull request, jobs, speed, title, directory and gjc version. It refreshes while it is open, and the full usage report stays one `Details` click away.

### Removed

- The conversation actions menu no longer carries `Session info and usage`; the toolbar button replaces it.
