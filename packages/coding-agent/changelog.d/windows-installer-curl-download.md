### Fixed

- The Windows installer downloads release assets with the system `curl.exe` (Windows 10 1803 and later) instead of from inside `powershell.exe`, and shows curl's progress bar for the ~160 MB binary. On one machine with AhnLab V3 Internet Security, downloads made from `powershell.exe` ran at 0.3-0.55 MB/s, an install taking several minutes to hours, while `curl.exe` ran at 46-84 MB/s from the same network at the same time; the link to that software is not proven. `curl.exe` uses the proxy `Invoke-WebRequest` would use (`[WebRequest]::DefaultWebProxy`, honouring its bypass list) and ignores proxy environment variables when that is a direct connection; a PAC file with different rules for the redirect host is not honoured. If `curl.exe` is missing or fails without an HTTP error status, the installer warns and falls back to `Invoke-WebRequest` (which shows no progress); an HTTP error status stays final. A download that fails now reports the cause instead of "No prebuilt GJC binary was found".
