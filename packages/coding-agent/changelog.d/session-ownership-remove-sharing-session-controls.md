### Removed

- SDK embedders: `SessionManager` no longer has the shared title and shared control publications: `setSessionNameSharingSession()`, `appendCustomEntrySharingSession()`, `appendCustomMessageEntrySharingSession()`, `appendTemporaryModelChangeSharingSession()`, `appendModelProfileActivationSharingSession()`, `appendServiceTierChangeSharingSession()`, `appendControlEntriesSharingSession()`, `appendCompactionSharingSession()`, `appendModeChangeSharingSession()`, `appendSessionRecapSharingSession()`, `appendToolSelectionsSharingSession()`, `appendTtsrInjectionSharingSession()`, `appendLabelChangeSharingSession()`, `contextClearControlEntries()` and `defaultModelSelectionControlEntries()`. The `SharedTitleOutcome`, `SharedControlEntry` and `ModelProfileTranscriptPlan` types are gone too. `SharedControlPublicationError` now only reports `rejected`; its `stale`, `unknown` and `committed_not_applied` codes are gone, and its constructor parameter and public `outcome` field narrowed from `SharedEntriesAppendOutcome` to `{ kind: "rejected"; error }`. Use the ordinary appends (`appendCustomEntry()`, `setSessionName()` and the rest): every session writes its transcript through them.
