### Fixed

- Startup model resolution now refreshes runtime-descriptor providers named by an explicit `--model` selector or the configured default. `refreshMissingQualifiedModelProviders` only consulted `getDiscoverableProviders()` — the discovery-manager set (models.yml `discovery:` entries and local runtimes) — so descriptor-backed providers like `devin` never refreshed before resolution: a fresh `gjc -p --model devin/swe-2-max` failed with `Model "…" not found`, and a config default pointing at such a provider degraded to last-profile recovery with a different model silently serving, while interactive sessions resolved the same selector because their full startup discovery sweep populates the registry. The provider lookup now falls back to the static `PROVIDER_DESCRIPTORS` table, so the awaited startup `refreshProvider(provider, "online-if-uncached")` also runs for descriptor providers and the models.db discovery cache (or a live fetch) satisfies the selector before the session picks a model.
