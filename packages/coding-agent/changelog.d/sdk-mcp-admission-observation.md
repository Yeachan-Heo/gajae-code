### Fixed

- SDK composer/HUD observations (`info`, `catalog`, `complete`) and the factory `jobObservation` view now stay readable while MCP control admission is held (an MCP suspend, resume or reconnect, or an internal conventional `/mcp` connect, disconnect or reconnect or exact-config suspend, resume or reconnect). Previously reads failed with `session_transitioning`, and any read of `jobObservation` during the admission disposed the view, which left bound activity controls permanently `stale_session` afterwards. Factory job mutations (monitor/task cancel, pause, resume, cron delete, failure acknowledgement) are refused with `session_transitioning` for the duration of MCP admission. Internal MCP paths that commit a new generation still retire the view, at the first getter read after the commit; behaviour outside MCP admission is unchanged.
