### Added

- Added implicit, keyless Rapid-MLX discovery at `http://localhost:8000/v1`, explicit `discovery.type: rapid-mlx` configuration, and served context-window metadata. Loopback discovery aborts after 500 ms and refuses redirects, so an unresponsive or redirecting server cannot stall startup or forward `RAPID_MLX_API_KEY`. A credentialed loopback probe goes over a direct socket, so `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` (including a proxy a project `.env` declared) never receives the bearer. The implicit probe only publishes entries that carry a Rapid-MLX-native field, so a vLLM-only server on port 8000 keeps its own `vllm` catalog, and that admission policy is part of the discovery cache provenance; an `offline` refresh does not publish implicit Rapid-MLX models, so one live probe establishes identity.
