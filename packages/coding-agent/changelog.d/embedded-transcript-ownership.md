### Added
- Add embedding helpers for applications that share transcripts with the terminal: `readEmbeddedTranscriptTail` reports a session's committed and held transcript tails (a repeat check on an unchanged file costs one `stat`), `isEmbeddedAppendRefused` reports the store's lasting refusal of a stale writer, `readEmbeddedTranscriptHistory` reads a transcript's conversation for display without opening a session or taking a writer, `isEmbeddedAncestor` decides whether a saved position was the end of the transcript before something was appended, and `findEmbeddedLiveOwner` asks the running broker, without starting one, whether a live process holds a transcript open, within a `timeoutMs` that also covers reading the broker's discovery file.
