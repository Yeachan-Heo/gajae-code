### Fixed

- `gjc sdk broker attest-spawn-anchors` now refuses a lifecycle ledger past the bounds the broker applies when it opens it (64 MiB, 10,000 rows, 8 MiB per row by default, shared with `LifecycleLedger`), so it no longer reports or writes an attestation the broker would never load. It also refuses an existing attestation larger than that byte bound or listing anything other than lowercase 64-character hex identities instead of republishing it, and does not publish a union past the byte bound (follow-up to #7533).
- The restart notice printed after `--write` now names the selected agent directory, shell-quoted, in every route: the supervisor route for `gjc sdk broker run --agent-dir <dir>`, the on-demand route through the next `gjc sdk` command with `--agent-dir <dir>` for installed builds, and `bun run restart:sdk-broker -- --agent-dir <dir>` for source checkouts only (follow-up to #7533).
