### Fixed

- `gjc sdk broker attest-spawn-anchors` now refuses a lifecycle ledger past the bounds the broker applies when it opens it (64 MiB, 10,000 rows, 8 MiB per row by default, shared with `LifecycleLedger`), so it no longer reports or writes an attestation the broker would never load. It also refuses an existing attestation larger than that byte bound or listing anything other than lowercase 64-character hex identities instead of republishing it, does not publish a union past the byte bound, and refuses an agent directory no broker can run for (follow-up to #7533).
- The restart notice printed after `--write` now names the selected agent directory, shell-quoted, in every route: the supervisor route for `gjc sdk broker run --agent-dir <dir>`, `gjc doctor --fix --repair service.restart-owned` (with `GJC_CODING_AGENT_DIR` set to that directory) for a running on-demand broker in installed builds, and `bun run restart:sdk-broker -- --agent-dir <dir>` for source checkouts only (follow-up to #7533).
