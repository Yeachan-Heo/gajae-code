### Features

- Allow user-level skill symlinks to resolve outside their scan root when `skills.trustUserSkills` is enabled (on by default). This aligns with how other editors (Claude Code, Codex, OpenCode, pi) handle symlinked skills, enabling users to maintain a shared skills repository and reference it via symlinks from their `.gjc/agent/skills` directory. When `skills.trustUserSkills` is false, outside-root symlinks are still refused; diagnostics recommend `skills.customDirectories` or enabling `skills.trustUserSkills`. User-link and target identities remain pinned while loading skill bodies. (fixes #6355)
