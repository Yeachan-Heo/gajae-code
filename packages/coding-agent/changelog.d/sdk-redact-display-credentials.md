### Fixed

- SDK activity controls no longer expose stored credentials in display fields. Job, task and cron labels, task model names, cron expressions and prompts, MCP server names and monitor output now show `[REDACTED]` in place of any stored API key, OAuth token or structured key token. Fields are masked before the SDK's own display limits, so those limits cannot cut a credential into a visible prefix. A value that was already cut upstream and ends in `...` or `…`, such as a long bash command label, has a trailing credential prefix of at least 8 characters masked as well; monitor output gets the same treatment at both ends of its retained window. Opaque refs and the controls they drive still act on the real job, task, cron or server.
- SDK activity `getDetail()` reports `outputTruncated` only when the masked output exceeds the output limit.
- SDK composer observation `info()` no longer exposes stored credentials in session name, cwd, model provider, id and name, model profile or HUD branch. Credentials hidden by terminal control sequences are masked as well, and a field is replaced entirely by `[REDACTED]` when display normalization would consume part of a credential.
