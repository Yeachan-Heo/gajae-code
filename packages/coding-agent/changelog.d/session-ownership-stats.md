### Added
- With session ownership turned on (`session.ownership.mode` set to `observe` or `enforce`), each gjc process adds its ownership counts to the local stats database when it exits: claims taken, released and refused, fail-open claims, locks still held at exit, writes without a claim, and the claim-set signals. `gjc stats --summary` and `gjc stats --json` show the all-time totals, the dates they span, and the same per gjc version with the number of processes that reported. `gjc stats` now also waits for a moment when another gjc process is writing the stats database, instead of failing with "database is locked". The counts stay on this machine. With the default `off`, nothing is counted or written, and `gjc stats` output is unchanged.
