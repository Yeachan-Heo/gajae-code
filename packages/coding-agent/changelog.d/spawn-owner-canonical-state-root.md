### Fixed

- `spawnedBy` on `gjc sdk search`, `gjc sdk session list` and `inspect`, and master peer snapshot rows is matched against the canonical (symlink-resolved) state root recorded when the spawned child registered. Previously the stored path spelling was re-resolved at listing time, so retargeting a symlinked state root could attach the old owner to a different host that later reused the child's session id. Spawn authority recorded before this change carries no canonical root, so its children (including ones still running across the upgrade) no longer show an owner on any row. An older Broker refuses to start against an agent directory whose spawn journal was written by this version, which affects downgrading or running a pinned older gjc against the same agent directory.
