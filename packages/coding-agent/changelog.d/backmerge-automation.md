### Changed

- `bun run release` now syncs the released commit into `dev` automatically: after the atomic `main` + tag push it merges `main` into `dev` in a throwaway worktree, resolving only the `packages/natives/native/diagnostic-artifact.json` build-digest conflict, retrying when `dev` genuinely moved under the merge, and reporting a manual recovery path instead of failing an already-published release.
- The changelog guard no longer reports the release flow's own fragment consumption as a violation. A fragment deleted by a `main`→`dev` backmerge is exempt only when that change actually shipped its note — every note line must be absent from the base CHANGELOG and present in the head CHANGELOG — so a normal PR deleting an unreleased note whose bullet text repeats an older release line is still rejected.
