### Fixed

- `gjc sdk spawn` no longer refuses a timely child host when another process holds the global session index lock until about 8.7 s past the admission deadline. The post-deadline registration recheck now lasts up to 20 s instead of 8 s, and still admits a late host only on its startup commit record. The recheck ends as soon as the outcome is decided: when a completed index read shows the host's recorded row no longer matches, when the host writes (or is writing) a failure receipt, or when the host process has provably exited. The last two also end a wait for the index lock. An owner whose process incarnation cannot be read is treated as uncertain and keeps the recheck open, so only a live, ready host behind a held lock waits out the bound.
