### Fixed

- `gjc sdk spawn` no longer refuses a timely child host when another process holds the global session index lock until about 8.7 s past the admission deadline. The post-deadline registration recheck now lasts up to 20 s instead of 8 s, and still admits a late host only on its startup commit record. The recheck ends as soon as the outcome is decided: when a completed index read shows the host's recorded row no longer matches, when the host's failure receipt becomes readable, or when the host process has provably exited. The last two also end a wait for the index lock. An owner whose process incarnation cannot be read is treated as uncertain and keeps the recheck open, and a row that fails only the read-time liveness check also keeps it open, until the outcome is decided or the 20 s bound passes.
